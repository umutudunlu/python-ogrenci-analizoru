# Öğrenci Not Analizörü

Python temellerini pekiştirmek için yazdığım bir konsol uygulaması.

## Neler Yapıyor?
- Kullanıcıdan ad-soyad ve 3 adet not alır.
- Ortalamayı hesaplayıp 2 basamağa yuvarlar.
- Ortalamanın tek mi çift mi olduğunu tespit eder.
- Öğrencinin harf/başarı durumunu belirler.
- Tüm verileri bir Python sözlüğünde dict birleştirip ekrana basar.
